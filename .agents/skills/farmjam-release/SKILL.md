# FarmJam release checks

Read [release validation](../../../docs/release-validation.md) before selecting a release gate. Run checks against the current tree and report the actual result, environment, and scope. Historical evidence is not current verification. Focused checks do not imply that the full release gate passed.

Use [contributing](../../../docs/contributing.md) for the gate commands and runner constraints, and [storage and updates](../../../docs/storage-and-updates.md) for the update safety contract. State unverified Safari/iPad, hosting, multi-tab, cross-release, and real-device performance limits when relevant.
