# FarmJam visual editing

Read [the visual editor guide](../../../docs/visual-editor.md) before using the development editor. It previews the real app and writes validated overrides to `src/data/visual-overrides.json`; it does not edit behavior or audio. For source artwork or layout changes, preserve the existing renderer and responsive placement conventions described in [architecture](../../../docs/architecture.md).

Review the changed scenes at desktop and compact landscape sizes. Use the focused visual-editor checks in [contributing](../../../docs/contributing.md) when editor behavior or saved override handling changes. Real device appearance still needs device review.
