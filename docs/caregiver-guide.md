# Caregiver guide

FarmJam supports voluntary play, with optional practice for children who want to try it. No lessons are required. A caregiver can set up profiles, choose musical starting points, read optional guides, and decide whether gentle learning hints are enabled.

## Profiles and setup

The main screen lists completed child profiles. Select a child to play, or choose **Add child** to open caregiver setup. If caregiver music familiarity has not been set yet, setup asks about it first. It then collects the child’s name and age range, lets the caregiver choose an avatar and starting instrument complexity, and offers an optional invitation to read guides. Setup can be canceled; an unfinished profile is not added.

The age range suggests a starting complexity and affects when optional hints can be offered. It does not measure musical ability or determine what a child can learn. Complexity can be changed later for each instrument. Setup does not ask a separate child musical-experience question; existing profile settings remain attached to that profile.

Use the pencil beside a profile to change its name, age range, and appearance. These edits remain a draft until saved. Cancel discards the draft. Deleting a profile requires a separate confirmation and removes only that profile and its per-child settings from this browser. Browser storage is not a backup.

## Settings

From the child menu, open **Settings** without starting audio. The tabs are:

- **Caregiver**: set music familiarity for explanations, and manage hints for the selected child.
- **Guides**: read optional guides and mark a guide as read explicitly.
- **Instruments**: available when a child is selected; choose the six instruments and adjust the selected instrument's complexity and display options.
- **Sound**: available during play; adjust the current session's instrument and scenery levels.

Instrument and display preferences are saved for each child. Caregiver familiarity is shared on this browser/device. Sound mix levels are session controls. Existing data is retained when these preferences change.

## Guides and help

Guides are optional reference material, organized into short task pages. Use Back, Next or the page selector to jump freely. The practice guide covers the room controls and all four stages. Opening or paging through a guide does not mark it as read; **Mark as read** is an explicit choice on the final page. New or unread guides have badges in the menu. Guide revisions can make previously read material appear new again.

Choose **Show gesture** to watch an example and **Replay gesture** to see it again. Examples use the game's own controls, start with Simple layouts, and offer a Slower speed. Instrument and practice examples can also preview the selected child's saved controls without changing their preferences. Guitar and ukulele examples show holding a chord before sweeping the strings. The practice pages demonstrate each stage separately, including count-in, highlighted actions, progress, accompanying instruments, and the stop/repeat/restart/leave controls. All examples are silent and cannot operate the game.

The **?** button opens contextual help with one tap. Help returns to the screen where it was opened. During play, gameplay Settings still opens with a double-tap of its button. In help and guides, explanations adapt to the caregiver familiarity setting.

## Learning hints

Hints offer brief suggestions for actions such as tapping, changing landscapes, equipping an instrument, or visiting practice. They never open by themselves. At most one suggestion is highlighted at a time, and selecting it shows a hand over the actual control in play, with a short caption and Replay gesture / Stop hint controls. There is no child hint dialog. Equipping and entering practice can continue into a second action after the child performs the first. Demonstrations never press controls or make sounds. Reduced-motion users see static contact and direction cues. Stopping dismisses a hint; an unfinished suggestion remains available after restarting.

Hint timing counts active, visible, focused play in landscape when dialogs are closed. Automatic suggestions have different age and activity defaults. These are product defaults, not developmental guidance. Caregivers can turn hints on or off for the selected child, reset an individual hint, or explicitly suggest one regardless of its automatic eligibility.

## Saving and offline use

Profiles and preferences are stored in this browser on this device. If a save fails, FarmJam keeps the current in-session choice where possible and shows a retry option. Do not clear browser site data if you need to retain profiles. The operating system or browser can evict local data.

The installable web app caches its shell and bundled audio after a successful online load. Updates wait until play, setup, guide/help dialogs, and unsaved changes are clear, then reload at a safe menu. Offline readiness and storage retention depend on the browser and device; see [storage and updates](storage-and-updates.md).
